# Tetris — Godot 4.5 (API8 Competition)

A **Tetris** game built in **Godot 4.5** featuring **3 game modes**, created for the **API8** competition.

> **Play Online:** *Link not yet published.*

---

## Features

* **3 Game Modes:** *NORMAL*, *BLITZ*, and *SURVIVAL*.
* **Retro Arcade Atmosphere:** Custom arcade typography (`arcadeclassic.ttf`) and dedicated music & sound effects (`menu.ogg`, `jeu.ogg`, `rotation.ogg`, `destruction.ogg`, `Game_OVER.ogg`).
* **Export Ready:** Pre-configured export settings included via `export_presets.cfg`.

---

## Project Structure 

* `project.godot` — Main Godot 4.5 project configuration.
* `tetris.tscn` — Main game scene.
* `tetris_code.gd` — Core gameplay, logic and game modes.
* `export_presets.cfg` — Project export presets.
* `arcadeclassic.ttf` — Arcade font asset.
* `*.ogg` — Background music and sound effects (`menu.ogg`, `jeu.ogg`, `rotation.ogg`, `destruction.ogg`, `Game_OVER.ogg`).

---

## Running Locally

1. Install **Godot 4.5**.
2. Clone the repository:
   ```bash
   git clone git@github.com:nibor606/Godot_Tetris.git
   ```
3. Open Godot 4.5, click **Import**, select `project.godot`, and run `tetris.tscn`.
